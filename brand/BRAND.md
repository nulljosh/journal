# Journal brand

A notebook. Off-white paper, dark ink, one blue for anything you can click. The words are the design, so nothing else competes with them.

## Color
Defined in `tokens.css`. The toggle in the corner switches light and dark.

| Role | Light | Dark |
|---|---|---|
| Accent | `#0a62d8` | `#0a62d8` |
| Link | `#0a58c2` | `#5aa9ff` |
| Paper | `#fcfcfb` | `#000000` |
| Card | `#f3f3f1` | `#1c1c1e` |
| Ink | `#1d1d1f` | `#f5f5f7` |

## Type
The system font. No webfonts. Code and dates in the system mono.

## Shape
Cards 28px, pictures 20px, the toggle is a circle. Spacing sits on the 8 point grid.

## Don't
- No cream, no clay. That was the old shared sheet.
- No second accent colour.
- Header art stays `currentColor` so it follows the theme.
